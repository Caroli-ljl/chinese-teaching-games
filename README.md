# 中文教学游戏

> 一份**可试玩的中文互动教学产品原型合集**：7 款独立 HTML 小游戏 + 支撑其运行的 CloudBase 云函数源码。
> 全站纯静态前端，可直接用浏览器打开；部分游戏的「AI 生成 / 排行榜 / 联机对战」依赖原 CloudBase 云环境在线。

---

## 一、仓库结构

```
chinese-teaching-games/
├── Chinese-games/                 七款游戏所在的文件夹
│   ├── index.html                游戏列表入口（点任一卡片即玩）
│   ├── kan-tu-xuan-pinyin.html   游戏1 · 看图选拼音
│   ├── hanzi-unit-match.html     游戏2 · 识字消消乐 · 分单元版
│   ├── qing-family-wheel.html    游戏3 · 青字家族大转盘
│   ├── pinyin-wheel.html         游戏4 · 拼音大转盘
│   ├── hanzi-wordcard.html       游戏5 · 智能汉字词卡（AI）
│   ├── coze-sentence-archive.html 游戏6 · Coze 飞书句子错误档案（AI）
│   ├── hanzi-pintu.html          游戏7 · 汉字拼图
│   └── lib/                      七款游戏共用的前端库（cloudbase SDK / 公共逻辑）
├── config.js                     占位符配置（部署时由 Secrets 注入真实值）
├── config.example.js             本地预览模板（复制为 config.local.js 填值）
├── content.js                    全站内容编辑系统前端（被各游戏加载）
├── cloudfunctions/               5 个云函数源码（运行在 CloudBase，不参与静态部署）
├── .github/workflows/deploy.yml GitHub Pages 部署流水线
└── README.md                     本文件
```

> 每个游戏页顶部都有常驻顶栏：**「← 返回列表」**（回到 `Chinese-games/index.html`）与 **「⏹ 结束」**（重载重开本游戏）。

## 二、如何运行

### 方式 A：直接打开（最快，无需任何后端）

1. 下载本仓库（或 `git clone`）。
2. 打开 `Chinese-games/index.html` —— 这是游戏列表总入口，点任一卡片的「▶ 试玩」即玩。
3. 也可以直接双击任意单个游戏 HTML（如 `Chinese-games/hanzi-pintu.html`）单独运行。

> 7 款游戏里 **1/2/3/4/7 是纯前端游戏**，不依赖任何后端，离线即可完整游玩。
> 游戏 5（智能汉字词卡）和 6（Coze 句子档案）的「AI 生成 / 批改」必须连原 CloudBase 云环境，详见各游戏「运行依赖」。

### 方式 B：本地预览（含云端功能的真实调用）

```bash
cp config.example.js config.local.js   # 填入你自己的 ENV_ID / ACCESS_KEY
# 然后用浏览器打开 Chinese-games/index.html 即可
```

`config.local.js` 已被 `.gitignore` 排除，不会被提交；CI 部署走的是仓库 Secrets 注入，与本地文件互不影响。

### 方式 C：部署为可在线访问的站点（GitHub Pages）

见文末「六、部署到 GitHub Pages」。

## 三、七个游戏逐个怎么用

### 游戏 1 · 看图选拼音 `kan-tu-xuan-pinyin.html`

**定位**：拼音认读 · 零基础游戏化入口。用 emoji / 图片做跨语言视觉锚点，把「图像 → 汉字 → 拼音」做成有节奏、有反馈的认读游戏。

**玩法步骤**
1. 在开始页**选择难度**（三档）。
2. 可选**自定义题库**：输入框里填汉字词语（如「西瓜」），系统自动匹配拼音与图案，勾选词语即可加入本轮练习；不填则用内置默认词库。
3. 输入**昵称**（用于云端实时擂台记录成绩；可留空，成绩只存本地）。
4. 点**「开始挑战」**：每题给出一张图 / 一个 emoji，从选项中选出正确拼音；答对触发连击加分、即时发音 + 释义反馈，限时计分。
5. 结束查看评级与正确率，可进入**错题复习**；顶部还有**查词**功能，输入任意词语即可查其拼音。
6. 页面内「🏅 实时擂台（前 3 名）」展示当前最高分玩家。

**运行依赖**：游戏主体纯前端，离线可玩（最高分存 `localStorage`）；实时擂台排行榜需 CloudBase 在线。

---

### 游戏 2 · 识字消消乐 · 分单元版 `hanzi-unit-match.html`

**定位**：分单元词库 · 贴合教材进度。把「消消乐」内核升级为按课文单元抽词，让教师对应教材进度布置练习。

**玩法步骤**
1. 顶部**「课文单元」下拉**选单元（数字 / 人称 / 亲属 / 学校 / 饮食 / 颜色 / 动作 / 自然，共 8 个单元）。
2. 点**「开始游戏」**进入配对消除（生字 ↔ 拼音 两两配对）。也可：
   - **「双人对战」**：同一台设备本地 PK，可选难度。
   - **「🌐 联机对战」**：跨设备实时比拼——一人「创建房间」拿到房间号，另一人输入相同房间号即可同步对战（用当前所选单元的生字），先消完者胜。
3. **「自定义词库」**：每行写一对 `汉字,拼音`（或空格分隔，如 `猫,māo` / `狗 gǒu`），可粘贴自己的生字表 / 课文词，一贴即用，仅作用于当前单元。
4. 开始前输入**昵称**，成绩、排行榜与学情数据按昵称归属（名字会自动记住）。

**运行依赖**：配对消除、自定义词库、本地双人对战均纯前端离线可用；联机对战与实时擂台需 CloudBase 在线。

---

### 游戏 3 · 青字家族大转盘 `qing-family-wheel.html`

**定位**：形声字字族 · 规律发现式教学。用转盘把抽象的「声旁表音、形旁表义」变成可玩的规律发现，直观展示青字族。

**玩法步骤**
1. 输入**昵称**（可选）。
2. 点**「开始游戏」**后点**「转动」**转盘。
3. 转盘停下后，看指针指向哪个字（青字族：清 / 晴 / 请 / 情 / 蜻 / 睛 / 静 / 精 / 靖 / 菁），从选项中选出它的**正确读音**。
4. 反复转动，在游戏中感受「同一声旁 → 读音相近、不同形旁 → 意义有别」的形声字规律。

**运行依赖**：纯前端，离线可玩；实时擂台需 CloudBase 在线。

---

### 游戏 4 · 拼音大转盘 `pinyin-wheel.html`

**定位**：拼音三档 · 随机暴露抗遗忘。用「转盘 + 听音选择」的随机重复暴露替代死记硬背，天然适配课堂随机点将。

**玩法步骤**
1. 选类别：**声母 / 韵母 / 整体认读**（三档可切）。
2. 点**「开始游戏」**→**「转动转盘」**，转盘随机停在一个拼音上。
3. 点**「听发音」**听该拼音对应的示例字，再回答下方的选择题。
4. 共 **10 题**，答对得分，结束查看结果。

**运行依赖**：纯前端，离线可玩（发音反馈由前端实现）；实时擂台需 CloudBase 在线。

---

### 游戏 5 · 智能汉字词卡 `hanzi-wordcard.html`

**定位**：AI 词卡 · 多模态生成 + 共享汉字表。输入汉字即调用云端工作流生成含图片 / 发音 / 例句 / 翻译的词卡，学生自生成组成共享汉字表。

**玩法步骤**
1. 在输入框输入**一个汉字或词语**（如「读」「书」「好」，支持单字或词语）。
2. 点**「✨ 生成词卡」**：调用云端工作流生成多模态词卡（图片 + 发音 + 例句 + 翻译）；若工作流无结构化输出，会自动改走智能体对话输出兜底。
3. 不满意可点**「↺ 重新生成」**。
4. 不断新建，组成**共享汉字表**（数据沉淀云端）；卡片可勾选标记为「学习中 / 复习中」，用顶部 tab 筛选，或用**「🔁 标记为复习」「🔄 复习模式」**轮播复习。

**运行依赖**：⚠️ **必须 CloudBase 在线**（调用云端工作流）。未配置 `ENV_ID` / `ACCESS_KEY` 或未连原环境时，生成会失败。

---

### 游戏 6 · Coze 飞书句子错误档案 `coze-sentence-archive.html`

**定位**：AI 批改 + 飞书沉淀 · 错题可追溯。先用 AI 生成情景图辅助看图说话造句，再即时批改，错误自动回流飞书多维表格形成可复盘档案。

**玩法步骤**
1. **第一步 · 生成情景图片**：输入一个生词（如「开心」「下雨」），点**「✨ 生成情景图片」**，AI 画出情景画面，帮助脑子里建立画面、降低造句门槛。
2. 点**「💾 保存到云端」**：图片压缩后持久保存，换设备也能看到；下方列出你已收藏的全部图片。
3. **第二步 · 写句子并批改**：在输入框写下句子，点批改，云端工作流**即时批改**；有错误时给出友好提示，错误自动回流飞书多维表格形成可复盘档案。

**运行依赖**：⚠️ **必须 CloudBase + Coze 在线**。演示版 AI 批改依赖 Coze 额度，偶发不可用属正常现象；真实错题数据沉淀在飞书侧。

---

### 游戏 7 · 汉字拼图 `hanzi-pintu.html`

**定位**：部件拼字 · 形义拆解游戏化。拖拽偏旁部件拼出目标字，建立「部件 → 整字」的字形结构认知，是笔顺 / 识字类产品的结构认知前置环节。

**玩法步骤**
1. **「老师自定义题库」**：在文本框输入要拆解的汉字（最多 50 个），系统自动拆解部件，填写词库名称，点**「🚀 生成游戏」**；也可以先把自己的生词存进**「我的词库」**。
2. 选择要练习的汉字、设置**练习题数**，点**「🚀 开始练习」**。
3. 进入拼字：把偏旁部件**拖拽**到装配槽拼出目标字；卡住时点**「💡 提示 -20」**（扣分提示）。
4. 连击计分 + **S / A / B / C 评级** + 错题回顾；结束可**「📤 导出复习单」**（生成打印友好的 HTML 复习表）。
5. 输入**昵称**后成绩可进入**云端实时擂台**存分。

**运行依赖**：拼字游戏主体纯前端，离线可玩；擂台 / 云端存分需 CloudBase 在线。

## 四、云函数源码（`cloudfunctions/`，运行在 CloudBase）

| 云函数 | 作用 | 依赖的环境变量（部署时设置，不进仓库） |
| --- | --- | --- |
| `contentApi` | 全站内容编辑系统的读写（按 `ckey` 覆盖静态文案） | `CONTENT_PASSCODE`（编辑口令） |
| `hskkApi` | HSKK 易错发音档案：分页拉飞书表格、脱敏、按维度分类 | `FEISHU_APP_ID` / `FEISHU_APP_SECRET` / `FEISHU_APP_TOKEN` / `FEISHU_TABLE_ID` |
| `hanziApi` | 智能汉字词卡：云端生成词卡 + 生词表增删查改 | CloudBase 环境内置 |
| `sentenceArchiveApi` | Coze 句子档案：生词→情景图、句子→批改 + 飞书存档 | 依赖 Coze / 飞书额度 |

> 这些函数只在原 CloudBase 环境运行、被前端匿名调用，本仓库仅存其**源码存档**，不参与 GitHub Pages 静态部署。

## 五、隐私与安全（重要）

- 本仓库**不包含任何真实密钥**。所有敏感值（CloudBase `ACCESS_KEY`、内容编辑口令、飞书凭据）都已从源码移除。
- 真实值通过 **GitHub 仓库 Secrets** 在部署时注入 `config.js`，**不进代码、不进 git 历史**。
- `ACCESS_KEY` 是 CloudBase 设计上就放在前端的**匿名可公开**密钥；但为防滥用，部署到 Pages 后建议到 CloudBase 控制台**轮换该 key** 使其失效，并收紧匿名安全规则（关闭匿名写敏感数据）。
- 本地预览用的 `config.local.js` 已被 `.gitignore` 排除，切勿将其提交。

## 六、部署到 GitHub Pages

### 1. 准备仓库 Secrets
仓库 **Settings → Secrets and variables → Actions** 添加：

| Name | 说明 |
| --- | --- |
| `ENV_ID` | CloudBase 环境 ID（如 `cloud-chinesegame-xxxx`） |
| `ACCESS_KEY` | CloudBase 匿名 publishable key（JWT） |

> 仅游戏 5 / 6 的 AI 功能需要这两项；纯前端游戏（1/2/3/4/7）即使不配 Secrets 也能玩。

### 2. 一键发布
```bash
gh auth login                              # 浏览器/设备码登录（首次需此步）
cd jialu-site
bash publish.sh                            # 建仓(若需)/推送/设 Secrets/启用 Pages
```

### 3. 启用 Pages
若 `publish.sh` 未能自动启用：仓库 **Settings → Pages → Source 选 GitHub Actions** 保存即可。
访问 `https://<用户名>.github.io/chinese-teaching-games/` 验证。

> ⚠️ **私有仓库 + Pages 的套餐限制**：GitHub 免费个人账号仅支持「公开仓库的 Pages」。
> 若你的账号是免费档且想保留私有仓库，需要 GitHub Pro / Team 才能开启私有仓库 Pages；
> 若不想升级，把仓库设为 Public 也**不影响隐私**——因为真实密钥从不进仓库（已改用 Secrets 注入）。

## 七、备注

- 站点全部使用**相对路径**，因此托管在 GitHub Pages 子路径（`/chinese-teaching-games/`）不会 404。
- 本仓库站点根目录没有 `index.html`，访问时请直接打开 `Chinese-games/index.html`（或单个游戏 HTML）。
- `cloudfunctions/` 仅为后端源码存档，不参与 Pages 静态部署；它们运行在 CloudBase 上。
- 游戏页顶部的「返回列表」与各游戏内「返回列表」按钮均指向 `Chinese-games/index.html`，不依赖任何已被移除的页面。
